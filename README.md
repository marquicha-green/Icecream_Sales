# 🍦 Ice Cream Sales Predictor

## Project Overview
This application predicts daily ice cream sales based on
weather conditions using a Linear Regression model.

## Features
- Select from eight US cities.
- Retrieve weather forecasts using the Open-Meteo API.
- Predict ice cream sales using temperature and rainfall.
- Display predicted sales and weather conditions.
- Provide recommendations based on expected sales.

## Technologies
- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy
- Open-Meteo Weather API

## Machine Learning Model
The application uses Linear Regression with two predictors:
1. Temperature (Fahrenheit)
2. Rainfall (inches)

The model was trained on simulated sales data for
educational purposes. Predictions are illustrative and
have not been validated against real business sales.

## How It Works
1. Select a city.
2. Choose a forecast date.
3. Click "Predict sales."
4. View the predicted ice cream sales.
